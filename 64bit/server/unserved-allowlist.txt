# method. One line per entry: the method as the report names it ("Class::method"; a trailing * matches a prefix),
# then the reason. The audit behind every entry: research/03-dll-engine-boundary/server-host.md section 11.
# A human-driven game goes through the proxy, which forwards these calls to the EXE (D21); this list is for headless.
#
